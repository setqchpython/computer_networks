# Отчет по практической работе: Проектирование и расчет IP-адресации в Cisco Packet Tracer

## Введение и цель работы

В рамках лабораторной работы по дисциплине «Компьютерные сети» было выполнено задание по проектированию локальной сети с использованием эмулятора Cisco Packet Tracer. Основная цель — освоить методику расчета масок подсетей (VLSM) и правильного распределения пула IP-адресов для сегментов сети с разным количеством узлов.

**Исходные данные:** базовая сеть `127.168.0.0/24`, которую необходимо разделить на 5 логических подсетей (по количеству зданий). В каждом здании находится от 15 до 25 оконечных устройств (ПК).

## 1. Теоретический расчет и обоснование маски

Для корректного разделения сети необходимо рассчитать маску подсети, которая покроет максимальное требуемое количество хостов без избыточного расходования адресного пространства.

*   **Анализ требований:** максимальное количество устройств в одном здании — 25.
*   **Учет служебных адресов:** для работы подсети всегда резервируются два адреса: адрес самой сети (Network Address) и широковещательный адрес (Broadcast Address). Следовательно, минимально необходимое количество адресов составляет $25 + 2 = 27$.
*   **Определение степени двойки:** ближайшая степень двойки, которая покрывает 27 адресов — это $2^5 = 32$. Это означает, что под адреса хостов (host bits) выделяется 5 бит.
*   **Расчет префикса:** общая длина IPv4-адреса — 32 бита. Длина префикса подсети вычисляется как $32 - 5 = 27$. Таким образом, префикс составляет **`/27`**.
*   **Маска подсети:** в десятичном формате маска `/27` соответствует **`255.255.255.224`**.

## 3. Ответы на дополнительные вопросы

В ходе защиты работы требовалось решить две задачи на расчет длины префикса:

*   **Задача 1: Определить префикс для сети с 10 узлами.**
    *   *Решение:* Требуемое количество адресов с учетом сети и broadcast: $10 + 2 = 12$. Ближайшая степень двойки — $2^4 = 16$. На хосты выделяется 4 бита, следовательно, префикс составляет **`/28`**.
    
*   **Задача 2: Определить префикс для разделения сети на 20 подсетей.**
    *   *Решение:* Для кодирования номера подсети в двоичном виде необходимо найти степень двойки, покрывающую число 20. Это $2^5 = 32$ (выделяется 5 бит). Суммарный префикс, учитывая исходную сеть, составит **`/29`**.
