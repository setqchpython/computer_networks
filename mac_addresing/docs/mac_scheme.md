# Анализ структуры MAC-адресов

**MAC-адрес** (Media Access Control) — это уникальный физический идентификатор, который присваивается каждому сетевому интерфейсу (например, сетевой карте). Он необходим для идентификации устройств на канальном уровне модели OSI.

Адрес имеет фиксированную длину — **48 бит**, что равно **6 байтам**. Для удобства чтения и записи он представляется в шестнадцатеричной системе счисления.

### Разбор на примере

Рассмотрим конкретный адрес: `00:1A:2B:3C:4D:5E`

| Байты | Назначение |
| :--- | :--- |
| `00:1A:2B` | **OUI** (Organizational Unique Identifier) — уникальный код производителя, закрепленный за конкретной компанией. |
| `3C:4D:5E` | **NIC** (Network Interface Controller) — уникальный серийный номер, который производитель присваивает конкретному устройству. |

### Классификация по способу рассылки

В зависимости от того, кому предназначен кадр, MAC-адреса делятся на три типа:

*   **Unicast (Одноадресный)** — кадр отправляется строго одному конкретному устройству (все 48 бит уникальны).
*   **Multicast (Многоадресный)** — передача данных группе устройств, которые подписаны на этот адрес.
*   **Broadcast (Широковещательный)** — кадр получают абсолютно все устройства в пределах локальной сети. В данном случае адрес состоит только из единиц и имеет вид: `FF:FF:FF:FF:FF:FF`.
