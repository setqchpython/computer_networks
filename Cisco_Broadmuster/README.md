# Отчет по лабораторной работе: Настройка фильтрации трафика средствами брандмауэра Windows

## Введение и цель работы

В рамках выполнения практического задания по дисциплине «Компьютерные сети» была изучена методика ограничения сетевой активности сторонних приложений с помощью встроенного брандмауэра операционной системы Windows.

**Основная цель** — освоить механизм создания правил блокировки входящего и исходящего трафика для конкретных исполняемых файлов, а также отработать навыки визуального подтверждения применения правил.

## Порядок выполнения работы

Для выполнения задания было необходимо ограничить сетевую активность программы Cisco (в данном случае использовался компонент `@FirewallAPI.dll`), чтобы продемонстрировать работу механизмов фильтрации.

**Алгоритм действий:**

1.  **Открытие оснастки.** Через панель управления или поиск Windows был запущен интерфейс «Брандмауэр Защитника Windows» и выбрано окно дополнительных параметров (Монитор безопасности / Расширенные настройки).
2.  **Создание правила.** В разделе «Правила для исходящего подключения» (или входящего) было создано новое правило типа «Блокировка подключения».
3.  **Указание пути.** В качестве целевого объекта был выбран исполняемый файл или библиотека, связанная с Cisco (путь: `@FirewallAPI.dll, -80204`).
4.  **Применение.** Правилу было присвоено имя «Блокировка Cisco», после чего оно было активировано и применено ко всем профилям сети (Домен, Частный, Общий).

## Результаты работы

После применения настроек в окне мониторинга брандмауэра было подтверждено, что созданное правило активно и применяется к указанному процессу. На скриншоте ниже зафиксирован момент работы правила, где напротив процесса Cisco отображается красная иконка, сигнализирующая о блокировке трафика.
