# Отчет по лабораторной работе: Исследование сетевого трафика в Wireshark

## Введение и цель работы

В ходе выполнения лабораторной работы по дисциплине «Компьютерные сети» было проведено исследование сетевого трафика с использованием программного анализатора протоколов Wireshark.

**Основная цель** — освоить интерфейс программы и приобрести практические навыки перехвата и анализа сетевых пакетов. Для выполнения задания был загружен заранее записанный дамп трафика (файл захвата), после чего произведен детальный разбор его элементов.

## Анализ интерфейса и структуры данных

В процессе работы были изучены три ключевые области окна программы Wireshark:

1.  **Панель списка пакетов (Packet List).** Представляет собой сводную таблицу всех перехваченных кадров. В ней отображаются порядковый номер пакета, временная метка, IP/MAC-адреса отправителя и получателя, используемый протокол, а также краткая сводка данных.
2.  **Панель детализации (Packet Details).** При выборе конкретного кадра (например, пакетов под номерами 751 и 760 на прилагаемом скриншоте) в этой области отображается иерархическая структура заголовков всех уровней модели OSI (от канального до прикладного).
3.  **Панель байтов (Packet Bytes).** Показывает шестнадцатеричный дамп (hex-код) выбранного пакета, что позволяет проанализировать его содержимое на уровне сырых данных.

## Результаты наблюдений

Практическая часть работы позволила закрепить навыки визуального анализа инкапсуляции сетевых протоколов. В ходе изучения списка кадров были идентифицированы пакеты транспортного уровня (UDP, TCP) и протоколы прикладного уровня.

На основе предоставленного скриншота были детально рассмотрены примеры широковещательных запросов к локальным службам именования — **NBTNS** (NetBIOS Name Service) и **LLMNR** (Link-Local Multicast Name Resolution), а также проанализирован процесс обмена данными на транспортном уровне.

## Заключение

Выполненная работа способствовала формированию базовых компетенций в области администрирования сетей и анализа трафика. Были отработаны приемы работы с анализатором Wireshark, необходимые для диагностики сетевых взаимодействий и выявления аномалий.
