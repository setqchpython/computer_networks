# Отчет по лабораторной работе: Анализ трафика в Wireshark и настройка брандмауэра

## 1. Цель работы
Исследовать сетевой трафик с помощью анализатора пакетов Wireshark, выявить соединения, инициируемые определенным программным обеспечением (например, ПО Cisco), и заблокировать нежелательную сетевую активность с помощью правил брандмауэра Windows (Windows Defender Firewall).

---

## 2. Ход выполнения работы

### Этап 1: Анализ трафика в Wireshark
1. Запущен перехват сетевых пакетов на активном сетевом интерфейсе в программе **Wireshark**.
2. С помощью фильтров (например, по IP-адресам, портам или конкретным протоколам) были обнаружены пакеты, относящиеся к приложениям или службам Cisco.
3. На основе собранных данных были зафиксированы IP-адреса назначения и используемые порты, через которые осуществлялась сетевая активность.

### Этап 2: Настройка брандмауэра Windows
Для блокировки обнаруженного трафика было создано правило в брандмауэре:
1. Открыта оснастка «Брандмауэр Защитника Windows в режиме повышенной безопасности».
2. Создано новое **Правило для исходящего подключения** (Outbound Rule).
3. В качестве критерия блокировки были указаны параметры, выявленные при анализе в Wireshark (порты, протоколы или конкретный исполняемый файл/путь).
4. Правило получило имя **«блокировка Cisco»** с действием **«Блокировать подключение»** для всех профилей (Доменный, Частный, Общий).

---

## 3. Результаты
На созданном скриншоте подтверждается успешное добавление правила блокировки в систему:

| Имя правила | Группа | Профиль | Действие |
| :--- | :--- | :--- | :--- |
| **блокировка Cisco** | — | Все | Заблокировать |

Благодаря настроенному правилу сетевые пакеты выбранного типа успешно перехватываются и блокируются брандмауэром ОС.
