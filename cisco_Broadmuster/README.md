## Суть работы
Исследован сетевой трафик с помощью анализатора пакетов Wireshark для выявления активности ПО Cisco, после чего было настроено правило брандмауэра Windows для блокировки нежелательных соединений. Цель — закрепить навыки анализа трафика и управления правилами сетевой безопасности.

## Задачи
1. **Задача 1:** Перехват и анализ сетевых пакетов в Wireshark, выявление целевых IP-адресов и портов, используемых программным обеспечением Cisco.
2. **Задача 2:** Создание правила для исходящего подключения («блокировка Cisco») в брандмауэре Защитника Windows для всех профилей сети.
3. **Задача 3:** Проверка успешности блокировки нежелательного сетевого трафика.

Работа закрепила практические навыки диагностики сети, выявления сетевых паттернов и настройки систем защиты уровня ОС.
