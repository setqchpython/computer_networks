# Отчет по практической работе: Расчет IP-адресации с применением технологии VLSM

## Введение и цель работы

В ходе выполнения расчетно-графического задания по дисциплине «Компьютерные сети» была проведена работа по планированию IP-адресации локальной сети с использованием технологии масок переменной длины (VLSM — Variable Length Subnet Mask).

**Основная цель** — освоить методы оптимального разделения адресного пространства на подсети с учетом реальных потребностей сегментов сети, а также закрепить навыки двоичной арифметики и применения принципов бесклассовой маршрутизации (CIDR).

## Решенные задачи и этапы выполнения

В процессе работы были выполнены следующие этапы проектирования:

1.  **Анализ исходной сети.** В качестве базовой была выбрана сеть класса C с префиксом `/24`, которую необходимо было разделить на несколько логических сегментов с разным количеством оконечных устройств.
2.  **Выбор оптимальных масок.** Для каждого сегмента была рассчитана маска подсети с минимально возможным количеством выделенных хостовых бит. Это позволило избежать неэффективного расходования адресов и минимизировать потери адресного пространства.
3.  **Определение диапазонов адресов.** На основе рассчитанных масок были сформированы списки доступных IP-адресов (диапазоны) для каждого сегмента, а также определены адреса сети и широковещательные адреса (Broadcast).

## Заключение

Выполненная работа позволила отработать практические навыки проектирования сетей с учетом реальных требований организации. Были рассмотрены случаи выделения как компактных сегментов (например, для серверных комнат), так и более крупных подсетей (для рабочих групп). Применение технологии VLSM показало свою эффективность для рационального использования ограниченного пула IPv4-адресов.
